# 霖林小屋 · 林间四时

在森林小屋停留片刻，探索向日葵花田、树梢动物、蝴蝶、蜜蜂与溪水。

在线体验：https://yjj0339.github.io/linlin-cottage/

支持电脑与手机。拖动旋转，滚轮或双指缩放。五种天气：晴日、晨雾、细雨、日落、星夜。通过底部按钮靠近花田、树梢和溪流；点击动物或打开图鉴可以观察林间邻居。

所有 Three.js 依赖、几何与场景代码均在仓库中，没有第三方模型或运行时图片请求。声音由 Web Audio 本地合成，默认关闭。
